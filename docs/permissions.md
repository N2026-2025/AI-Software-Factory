# Security and Permissions

## Secrets
- `IBM_QUANTUM_TOKEN`: Only for real QPU access. Never commit to repository. Use `.env` or CI secrets.
- `OPENROUTER_API_KEY`: Used by AI agents for refactoring. Store in environment variables only.
- Database credentials: Provided via `DATABASE_URL` environment variable, never hardcoded.

## Sandbox
- Code generated by LLMs (refactored Qiskit) must be validated before execution.
- Quantum jobs run in local Qiskit Aer simulator (deterministic, no external network required).
- MCP server runs stdio-only; no file system write access outside `/tmp`.

## Data
- No customer data or credentials are sent to telemetry.
- Logs are structured JSON and contain only `trace_id`, HTTP metadata, and duration.
